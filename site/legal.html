Open source and legal

Open, credited, and independent.

Tally is free software, built in the open on the work of others. This page says whose, under which licenses, and what Tally is not.

License

Tally, the apps and the server plugin, is free software under the GNU General Public License, version 2, the same license as Wholphin. You can use, study, share and change it under that license's terms. The complete source for every release is in the public repository, and each release on GitHub is built from the tag it's attached to. The repository's NOTICE.md sets out what Tally changed and when.

Built on Wholphin

Tally started as a fork of Wholphin, the open-source Android TV client for Jellyfin by damontecres and its contributors, and it wouldn't exist without it. The player, the library, settings and most of what happens between pressing play and a picture appearing are Wholphin's work, along with its contributors and translators.

Tally's changes began in September 2026, after Wholphin's v1.0.8 release. Tally's own code lives in its own package, and changes to Wholphin's files are small and marked in place. Tally isn't affiliated with, reviewed by or endorsed by the Wholphin project, and has its own name, icon and app id so it can't be mistaken for it. Please report Tally problems to Tally. If you like Tally, give Wholphin a star too.

Sources and rights

Tally is a media player. It doesn't host, provide, sell, index or link to any channels, streams or video, and it isn't a way to get any. It plays what's on your Jellyfin server and the live TV sources you add to it yourself: a paid IPTV subscription, an HDHomeRun or antenna tuner, or your own M3U playlists and HLS streams. You're responsible for having the rights to what you add and watch.

The optional server plugin reads public scoreboard data (scores, clocks, game situations) at run time to show and match games. Tally stores no league or team marks, and this website shows none.
