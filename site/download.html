About the security warnings

Tally's installers aren't signed with a paid code-signing certificate, and the app isn't installed from a store, so your devices will warn you the first time: Android asks you to allow installs from Downloader or your browser, Windows SmartScreen says "Windows protected your PC", and macOS refuses a program from an unidentified developer. Each guide below shows the exact step past the warning. Every file comes from the official release, built from the public source at its tag.

Android TV · Google TV · Fire TV · Nvidia Shield

Android TV and Fire TV

For Android TV, Google TV (including the Chromecast with Google TV), Fire TV and the Nvidia Shield. If the server's owner sent you a link, open it on your phone and follow it instead: it's the same steps, and the Tally it gives you already knows the server's address.

  1. Get Downloader on the TV

    Open the TV's app store, search for Downloader (orange icon, by AFTVnews) and install it. It's only used to install Tally.

  2. Open Downloader

    Choose Allow if it asks about files.

  3. Type this address and press Go

    https://github.com/Scdouglas1999/Tally/releases/latest/download/Tally.apk

  4. Press Install

    The first time, the TV says it isn't allowed to install unknown apps: choose Settings, switch Downloader on, press Back, then Install again. This is Android's normal step for an app from outside the store.

  5. Open Tally and sign in

    With Quick Connect, the TV shows a 6-digit code: in Jellyfin on your phone, open your profile, then Quick Connect, and type it. Nobody types a password with the remote.

You can delete Downloader afterward. When a new version is out, Tally shows an update screen by itself: press Download & Update. Tally installs next to the official Jellyfin app and Wholphin, and doesn't replace either.

Samsung smart TVs · 2020 and newer · Tizen

Samsung TVs

The full Tally, with sports, multiview and the player, built as a TV web app. The TV app comes from your server's plugin, so plugin updates also update the TV.

  • ServerThe Jellyfin server needs the Tally plugin, 2.1 or newer. Ask its owner.
  • ComputerWindows 10 or 11, a Mac, or Linux, on the same network as the TV, with internet the first time.
  • 2023 and newerThese TVs also need a free Samsung account, once.
WindowsTally-Samsung-Installer-windows.exeDownload Mac with Apple siliconTally-Samsung-Installer-macos-arm64Download Mac with IntelTally-Samsung-Installer-macos-x64Download LinuxTally-Samsung-Installer-linuxDownload

  1. Open the installer on the computer

    • Windows: double-click it. The first time, Windows may show "Windows protected your PC", because the program is new and not from a large company. Click More info, then Run anyway. A black window opens: that's the installer.
    • Mac: macOS won't open a downloaded program from an unidentified developer by double-clicking. Open Terminal and run these lines (use x64 instead of arm64 on an Intel Mac):
    cd ~/Downloads
chmod +x Tally-Samsung-Installer-macos-arm64
xattr -d com.apple.quarantine Tally-Samsung-Installer-macos-arm64
./Tally-Samsung-Installer-macos-arm64
    • Linux:
    chmod +x Tally-Samsung-Installer-linux && ./Tally-Samsung-Installer-linux

    Near the top it shows This PC's address, like 192.168.1.20. Write it down and leave the installer open.

  2. Turn on Developer Mode on the TV

    Open Apps and type 1 2 3 4 5 with the remote (on a slim remote, press 123 to bring up numbers). Switch Developer mode on, type the computer's address as Host PC IP, and press OK. Then restart the TV fully: hold the power button for about 5 seconds until the Samsung logo appears.

  3. Let the installer put Tally on the TV

    Back at the computer, pick your TV, type the Jellyfin server's address and press Enter. It installs Tally and starts it. TVs from 2023 on ask you to sign in with a Samsung account once.

  4. Sign in on the TV with a code

    Tally shows a 6-digit code. In Jellyfin on your phone, open your profile, then Quick Connect, and type it.

Keep the installer's folder (%APPDATA%\Tally\Samsung on Windows, ~/.config/Tally/Samsung on Linux): a reinstall later has to come from the same computer or a copy of it. Stuck? The full Samsung guide covers every screen and every installer message.

LG smart TVs · 2020 and newer · webOS 5+

LG TVs

The same full Tally as on Samsung, and the Magic Remote's pointer works as well as its arrow keys. Multiview plays the tile you're on and shows live cards for the others, because LG TVs play one video at a time.

  • ServerThe Jellyfin server needs the Tally plugin, 2.2 or newer.
  • ComputerWindows, Mac or Linux, on the same network as the TV.
  • LG accountA free LG developer account, from webostv.developer.lge.com.
WindowsTally-LG-Installer-windows.exeDownload Mac with Apple siliconTally-LG-Installer-macos-arm64Download Mac with IntelTally-LG-Installer-macos-x64Download LinuxTally-LG-Installer-linuxDownload

  1. Download the installer, but don't open it yet

    Set up the TV first.

  2. Turn on Developer Mode on the TV

    Install Developer Mode from the TV's app store, open it and sign in with your LG developer account. Switch Dev Mode Status on and let the TV restart. Open Developer Mode again and switch Key Server on. Leave that screen up: it shows a passphrase.

  3. Open the installer

    Windows: double-click it; at "Windows protected your PC", click More info, then Run anyway. Mac: in Terminal (use x64 on an Intel Mac):

    cd ~/Downloads
chmod +x Tally-LG-Installer-macos-arm64
xattr -d com.apple.quarantine Tally-LG-Installer-macos-arm64
./Tally-LG-Installer-macos-arm64

    Linux: chmod +x Tally-LG-Installer-linux && ./Tally-LG-Installer-linux

    Pick your TV, type the passphrase from the TV, then the server's address. It installs Tally and starts it.

  4. Sign in on the TV with a code

    Tally shows a 6-digit code. In Jellyfin on your phone, open your profile, then Quick Connect, and type it.

Developer Mode, kept on

LG's Developer Mode normally runs out after about 50 hours and removes the app. Once someone has signed in to Tally on the TV, your Jellyfin server renews Developer Mode every day, so Tally stays. Stuck? The full LG guide covers every screen.

Jellyfin 10.10 · 10.11 · 12.1 and later

The server plugin

The plugin runs inside Jellyfin. It adds the Sports section, live channels with a guide, the stream ladder, Tally Pulse, the DVR, Tally for Samsung and LG TVs, the Tally look for Jellyfin web, and an install page for your friends. Pick the way that matches how you run Jellyfin; every one keeps the plugin updated through Jellyfin's own plugin updates.

Windows

Tally-Server-Setup.exeAdds Tally to your Jellyfin, or installs the official Jellyfin first · about 58 MBDownload

Run it and press Install; Windows asks for administrator rights so the setup can stop and start Jellyfin. It finds your Jellyfin, adds Tally, keeps your libraries, users and settings, and starts Jellyfin again. With no Jellyfin, it downloads the official one from repo.jellyfin.org first. If SmartScreen warns about an unrecognized app, choose More info → Run anyway.

Docker

docker-compose.ymlThe official jellyfin/jellyfin image with Tally added before it startsDownload

Put the file in an empty folder, add your media folders to its volumes: list, set TZ to your time zone, and run:

docker compose up -d

It uses Jellyfin 12.1 unless you set JELLYFIN_VERSION (for example 10.10.7). Already running Jellyfin in Docker? Copy the file's tally-plugin service into your own compose file.

Debian and Ubuntu

curl -fsSL https://github.com/Scdouglas1999/Tally/releases/latest/download/install-linux.sh | sudo bash

Installs the official Jellyfin first if it's missing (from Jellyfin's own apt repository), then puts the right Tally build in place and restarts Jellyfin. It needs systemd. Read the script before you run it, if you like.

Any server: Jellyfin's plugin catalog

In Jellyfin, go to Dashboard → Plugins → Manage Repositories (on 10.10: Dashboard → Catalog, then the gear icon), and add a repository named Tally with this URL:

https://raw.githubusercontent.com/Scdouglas1999/Tally/main/server/manifest.json

Install Tally from the catalog (under Live TV), then restart Jellyfin. Jellyfin picks the build for its own version.

Manual install

Unpack the zip for your Jellyfin line into a Tally_<version> folder in Jellyfin's plugins folder, owned by the user Jellyfin runs as, and restart Jellyfin.

Then invite people

In Jellyfin, open the Tally page (Sports in the menu, or Dashboard → Tally), then Settings → Tally on a TV: a link, a QR code and a Share button. A friend who opens the link gets the Android TV steps with your server filled in and signs in from their phone. If friends reach your server from outside your home, set Public server address under TV app install link first.

Then add your live TV

In the Tally page, Settings → Sources → Add source: an M3U playlist with an optional XMLTV guide (your IPTV service's, or your HDHomeRun's lineup), or single HLS streams by name and address. Only add sources you have the rights to watch. Reload the browser tab once after installing the plugin to see the Tally look.

Everything else

Other devices

  • Web browserNothing to install. With the plugin, Jellyfin's web client gets the Tally look and a Sports page. The server's owner can turn this off in Tally's settings.
  • Xbox, JMPTheir Jellyfin apps load the server's web client, so the Xbox app and Jellyfin Media Player on a computer get the same Tally look.
  • iPhone, iPadNo Tally app yet. The official Jellyfin app for iPhone and iPad is built on Jellyfin's web client, so it gets the Tally look and Sports page, as does Jellyfin in Safari.
  • Apple TV, RokuNo Tally app yet. Their Jellyfin apps still get Tally's live channels, guide and game cards through Jellyfin's Live TV.
